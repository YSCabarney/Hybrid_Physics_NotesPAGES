Part 2 · Breaking diagonal forces into components

8 pts · calculator OK
📌 Recall — SOHCAHTOA
You've used cos and sin to break diagonal vectors into horizontal and vertical pieces. Forces work the same way — same formulas, same process, new context.
Horizontal
Fₓ = F cos θ
Vertical
F_y = F sin θ
Net magnitude
F_net = √(Fₓ² + F_y²)
Direction
θ = tan⁻¹(|F_y| ÷ |Fₓ|)
⚽ Worked Example — The Kicked Ball
A player kicks with 25 N at 40° above horizontal.

Fₓ = 25 × cos 40° = 25 × 0.766 = 19.2 N (forward)
F_y = 25 × sin 40° = 25 × 0.643 = 16.1 N (upward)

The kick is simultaneously 19.2 N pushing the ball forward and 16.1 N lifting it off the ground.

Part 3 · Adding forces — finding net force

8 pts
📌 Recall — Adding vectors
Break each force into Fₓ and F_y → add all Fₓ (keeping signs) → add all F_y → Pythagorean theorem for magnitude → tan⁻¹ for direction. Exact same process you used to add displacement vectors.
🛶 Worked Example — Two Ropes, One Boat
Rope A: 30 N due east. Rope B: 40 N due north.

Net Fₓ = +30 N    Net F_y = +40 N
F_net = √(30² + 40²) = √2500 = 50 N
θ = tan⁻¹(40 ÷ 30) ≈ 53° N of E

The boat responds to one resultant: 50 N at 53° N of E. It has no idea two ropes are pulling it.

Part 4 · Equilibrium & reflection

3 pts
🆕 Key idea — Equilibrium
When net force = 0, the object is in equilibrium: it stays still or keeps moving at constant velocity. Equilibrium does not mean the object isn't moving — it means its motion isn't changing. This is Newton's First Law.
